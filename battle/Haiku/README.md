# Alley Riot

2.5D side-scrolling beat 'em up на Three.js. Один герой, три уровня, три типа врагов и три босса.
Вся графика процедурная (CanvasTexture и примитивы Three.js), звук синтезируется через Web Audio API.
Внешних изображений и аудиофайлов нет. Музыки нет, только звуковые эффекты.

## Требования

- Node.js 18+ и npm (проверено на Node 24 и npm 11).
- Браузер с WebGL и Web Audio: Chrome, Firefox, Safari.

## Запуск

```bash
npm install
npm run dev       # dev-сервер, по умолчанию http://localhost:5173
npm run build     # production-сборка в dist/
npm run preview   # просмотр собранной версии
```

## Управление

| Действие | Клавиатура | Геймпад |
| --- | --- | --- |
| Движение влево / вправо | ← → или A D | левый стик, крестовина |
| Движение по глубине (полосы) | ↑ ↓ или W S | левый стик вверх / вниз |
| Прыжок | Space | A |
| Удар (комбо из трёх ударов) | J или Z | X |
| Удар ногой | K или X | Y |
| Спин-кик (перезарядка 3.5 с) | L или C | B |
| Захват / отпустить врага | G | LB или RB |
| Бросок захваченного врага | J (пока держите врага) | X |
| Пауза | P или Esc | Start |
| Выход в меню из паузы | Q | — |
| Звук вкл / выкл | M | — |
| Подтверждение в меню | Enter или Space | A или Start |

Рекорд сохраняется в `localStorage` браузера.

## Модули и взаимодействие

Спецификация требует одиннадцать модулей. Соответствие такое:

1. **Core** — `core/Game.js`, `core/StateMachine.js`, `core/states.js`. Game создаёт общий контекст `world`
   (scene, renderer, input, audio, fx, combat, hero, level) и передаёт его всем сущностям.
2. **Renderer** — `renderer/Renderer.js`. Поле зрения подбирается так, чтобы по горизонтали всегда было видно
   20 единиц мира, независимо от размера окна. Камера лёгким наклоном даёт перспективу.
3. **Input** — `input/Input.js`. Игра работает с действиями (`attack`, `jump`), а не с клавишами.
4. **Physics** — `physics/Physics.js`. Гравитация, AABB-коллизии, препятствия блокируют сущность, если та ниже их
   верхней грани.
5. **Entities** — `entities/`. Базовый `Entity` даёт физику, здоровье, таймеры оцепенения и неуязвимости, падение
   и визуальную модель.
6. **Combat** — `combat/Combat.js`. Хитбоксы создаются атакой и следуют за владельцем. Каждый кадр `Combat`
   проверяет пересечения с целями и вызывает `damage()`: урон, блок спереди, нокбэк, подбрасывание, оцепенение,
   неуязвимость, счётчик комбо, очки, звук и искры.
7. **AI** — `ai/EnemyAI.js`. Конечный автомат. Одновременно атакуют не больше двух врагов: это токены уровня
   (`Level.acquireToken`). Босс токенов не требует. Остальные держат дистанцию и ждут.
8. **Level** — `level/`. Камера едет за героем, но никогда назад. Когда левый край камеры доходит до точки волны,
   камера блокируется до зачистки волны. После зачистки сохраняется чекпоинт.
9. **UI** — `ui/`. HUD обновляет текст и ширину полос. Меню — отдельные HTML-экраны.
10. **Audio** — `audio/Audio.js`. Восемнадцать эффектов из осцилляторов, фильтров и шума. Для каждого звука
    есть защита от наложения.
11. **Assets** — `assets/`. Текстуры рисуются на canvas и кэшируются. Гуманоид собран из боксов и сфер,
    а конечности поворачиваются вокруг осей шарниров.

Порядок обновления кадра: `input.update()` → `states.update()` → `level.update()` (герой, враги, коллизии,
хитбоксы, снаряды, волны, камера) → `fx.update()` → `hud.update()` → `render()`.

## Этапы спецификации

| Этап | Реализация |
| --- | --- |
| 1. Настройка проекта | `package.json` (Vite, three), `index.html`, `main.js`, сцена и камера в `Renderer.js`, земля в `Level.js` |
| 2. Ядро | `Game.js`: rAF с delta time (не больше 50 мс за кадр), состояния меню, паузы и game over. `Input.js`: клавиатура и геймпад |
| 3. Герой | `Hero.js`: ходьба, прыжок, гравитация, посадка. Анимации idle, walk, jump, падение, удар через `Animator.js` |
| 4. Бой | `Combat.js` и `Hero.js`: хитбоксы, урон, нокбэк, неуязвимость, комбо из трёх ударов, спин-кик с перезарядкой, захват и бросок |
| 5. Враги | `enemyTypes.js`: grunt, agile, brute и боссы. `EnemyAI.js`: patrol, chase, windup, strike, recover, retreat, block, dodge, stun, down |
| 6. Уровни | `levels.js`: Night Street, Dojo, Industrial District. Прокрутка и волны в `Level.js`, параллакс в `Background.js`, ящики и бочки в `Obstacle.js`, чекпоинты в `Level.js` |
| 7. UI | `HUD.js`, `Screens.js`, `hud.css`: здоровье, жизни, счёт, название уровня, полоса босса, комбо, меню |
| 8. Звук | `Audio.js`: удары, попадания, прыжок, приземление, блок, взрыв, аптечка, рёв босса и др. Музыки нет |
| 9. Полировка | `Particles.js` (искры и пыль без создания объектов на кадр), `Pool.js` (пул снарядов), кэш геометрий и текстур, frustum culling (встроен в Three.js) |

## Геймплей

- **Герой.** Три удара подряд образуют комбо: два удара руками и третий, удар ногой, сбивает врага с ног.
  Спин-кик с прыжком даёт круговой удар и неуязвимость на время вращения. Захват (G) удерживает врага перед героем,
  бросок (J) отбрасывает его.
- **Враги.** *Grunt* — базовый. *Agile* — быстрый, уклоняется от атак героя. *Brute* — тяжёлый, блокирует
  удары спереди и не оглушается лёгкими ударами.
- **Боссы.** *Crusher* (уровень 1), *Sensei* (уровень 2), *Foreman* (уровень 3). Ниже 50% здоровья босс
  впадает в ярость: быстрее двигается и атакует с меньшим замахом. Foreman держит дистанцию и бросает
  снаряды.
- **Препятствия.** Ящики ломаются за три удара и роняют аптечку (+20 HP). Бочки взрываются от одного удара
  и наносят урон по площади. Препятствия блокируют движение, но удары сквозь них проходят.
- **Жизни и чекпоинты.** У героя три жизни. При гибели он возрождается у последнего чекпоинта, то есть после
  последней зачищенной волны. Враги текущей волны появляются заново.
- **Счёт.** Очки за урон, за убийства (100–250, боссы — 2000) и бонус 1000 за пройденный уровень.

## Заметки

- Графика и звук полностью процедурные. Все параметры баланса вынесены в `level/levels.js` и
  `entities/enemyTypes.js`.
- Предупреждение Vite о размере чанка (около 600 КБ) связано с самим Three.js. Это ожидаемо для проекта без
  разбиения на части.

## Что проверено и что нет

- Сборка (`npm run build`) проходит без ошибок.
- В браузере проверены: титульный экран, все три уровня, комбо и добивание, спин-кик, захват и бросок,
  прыжок, препятствия, аптечка, чекпоинт и гибель героя, game over, победа, пауза, выход в меню, звуковые
  эффекты (все вызываются без исключений), бой с боссами Crusher, Sensei и Foreman.
- Баланс (здоровье врагов, урон, тайминги боссов) не настраивался по результатам живых игровых сессий.
- Геймпад реализован через Gamepad API, но на реальном контроллере не проверен.
- Звук проверен на уровне вызовов Web Audio API, но на слух не оценивался.
